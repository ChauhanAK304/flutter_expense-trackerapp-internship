# Flutter Expense Tracker 💰

A complete Expense Management application built with **Flutter** and **Firebase**. This app helps users track their daily income and expenses with a real-time dashboard.

##  Key Features
* **Firebase Auth:** Secure login and sign-up for every user.
* **Smart Dashboard:** Real-time calculation of Total Income, Total Expense, and Balance.
* **Full CRUD:** Users can Add, View, Edit, and Delete transactions easily.
* **Transaction Filters:** Filter history by 'All', 'Income', or 'Expense' to track spending.
* **Responsive UI:** Clean interface using GetX for smooth navigation and state management.

##  Tech Stack
* **Framework:** Flutter
* **Database:** Cloud Firestore (NoSQL)
* **Authentication:** Firebase Auth
* **State Management:** GetX

##  How to Use
1. Clone the repo: `git clone https://github.com/ChauhanAK304/flutter_expense-trackerapp-internship.git`
2. Run `flutter pub get` to install all required packages.
3. Connect your own Firebase project by adding the `google-services.json` file.
4. Run the app: `flutter run`
